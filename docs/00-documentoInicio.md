## 2. Nombre del proyecto

DeckIt
Servicio web de compra/venta entre personas, tipo vinted/wallapop para juegos de sobremesa (Cartas, Rol, Etc...)

## 3. Qué quiero hacer

Una plataforma de compra y venta donde los usuarios pueden ofrecer en venta productos de juegos de mesa (Ya sean cartas, Juegos de rol u otros) o derivados (Para juegos de cartas, alfombrillas de juego o cajas de bajaras), y los interesados podran comprar dichos articulos, o hablar con el vendedor para hacer una oferta (ya sea monetaria o de intercambio, cada vendedor podra indicar si el intercambio esta aceptado por cada producto)

La Plataforma tambien podria ofrecer servicios para las tiendas especializadas, ofreciendoles publicar productos (por una pequeña comision) y anuncios de eventos (torneos, sesiones de juego)

## 4. Qué problema o necesidad resuelve

Cubre la necesidad de encontrar ciertos productos de manera local, sin necesidad de depender en webs internacionales

## 5. Para quién

Usuarios aficionados a los juegos de mesa, los cuales quieran completar su collecion a precios razonables o deseen probar otros juegos de las mismas ramas 

## 6. Funcionalidades principales

| # | Funcionalidad | ¿Imprescindible? (sí / no) |
|---|---|---|
| 1 | **Registro y gestión de perfiles de usuario**: Autenticación segura de usuarios, gestión de perfil público y reputación. | Sí |
| 2 | **Catálogo de productos con búsqueda y filtros**: Publicación de artículos (cartas, juegos de rol, accesorios) con fotografías, precio, estado de conservación e indicador de si acepta trueque/intercambio. | Sí |
| 3 | **Sistema de ofertas y negociación (Chat/Trueque)**: Chat en tiempo real o sistema de mensajería para acordar ofertas económicas o de intercambio directo entre usuarios. | Sí |
| 4 | **Sistema de valoraciones y reseñas**: Calificación mediante puntuación y comentarios tras finalizar una transacción o trueque para construir confianza. | No |
| 5 | **Módulo para tiendas especializadas y eventos**: Publicación de catálogo comercial por parte de tiendas locales e información sobre torneos y partidas organizadas. | No |
